# 读懂 Transformer 要先会什么

目标是读 Vaswani 等人 2017 年的模型章节，并把 Q、K、V 的形状自己推出来。训练细节和后来的工程优化分开排。

规划阶段见 [README.md](README.md)。论文导读见 [attention-is-all-you-need.md](attention-is-all-you-need.md)。

## 读第 3 节之前的最小集

矩阵乘法与点积、softmax、线性层和词嵌入、残差与 LayerNorm、编码器–解码器的自回归，以及「注意力是对值向量的加权和」。这六项对齐后，多头和掩码是组合，不是新的数学。

## 六项要到什么程度

<a id="stage-matrix"></a>

### 矩阵乘法、转置、点积

给定两个矩阵的行列数，能写出乘积的形状；知道点积大表示方向更接近。

细读和手算例子在 [01-matrix-and-dot-product.md](01-matrix-and-dot-product.md)。用在 `QKᵀ` 为什么是 `n×n`，以及 `W^Q` 为什么是 `d_model×d_k`。

<a id="stage-softmax"></a>

### Softmax

能写出 exp 再归一化；知道输入差很大时，质量几乎集中到一个位置，梯度接近 0。

细读和手算例子在 [02-softmax.md](02-softmax.md)。用在注意力权重，以及除以 `√d_k` 的那条脚注。

<a id="stage-linear"></a>

### 线性层与 ReLU、词嵌入

会写 `y = xW + b`，以及 `max(0, ·)`。知道 token 编号查表得到一行向量，这张表是参数。

用在三套投影和

```text
FFN(x) = max(0, x W1 + b1) W2 + b2
```

词嵌入对应论文第 3.4 节；嵌入与 softmax 前的线性层共享权重。

<a id="stage-residual"></a>

### 残差与 LayerNorm

会写 `LayerNorm(x + Sublayer(x))`；知道归一化是为了让深层加得动。

每个子层外面都有这一层，因此所有子层宽度必须同为 `d_model`。

<a id="stage-seq2seq"></a>

### 编码器–解码器

能说明训练时解码器看到的是已经给定的前缀，预测的是下一个词。

对应论文图 1、解码器嵌入右移一位、自回归。

<a id="stage-attention"></a>

### 加权求和式注意力

能说明权重来自查询和键的匹配，输出是值向量的加权和。

这是论文第 3.2 节的定义。加性注意力的小网络可以只记结论。

<a id="stage-shapes"></a>

## 用一组形状检验

设句长 `n = 4`，`d_model = 512`，头数 `h = 8`，于是 `d_k = d_v = 64`。论文按头分开写投影。下面每一行都应该能独立推出来。

| 量 | 形状 | 怎么来的 |
| --- | --- | --- |
| 一层的输入 X | 4 × 512 | 4 个位置，每个位置 512 维 |
| 单个头的 W^Q、W^K、W^V | 512 × 64 | 把 512 维投到该头的 64 维 |
| 单个头的 Q、K、V | 4 × 64 | X 乘对应投影 |
| QKᵀ | 4 × 4 | 每个查询对 4 个键各打一个分 |
| softmax 之后 | 4 × 4 | 每一行是一个查询的注意力分布，行和为 1 |
| 乘 V 之后 | 4 × 64 | 用这行权重混合 4 个值向量 |
| 8 个头拼接 | 4 × 512 | 8 × 64 = 512，回到 d_model |
| 再乘 W^O | 4 × 512 | W^O 是 512 × 512，便于残差相加 |

实现里常把 8 个头合成一个 `512×512` 的投影再切开，乘积形状与上表相同。解码器自注意力还要把 `QKᵀ` 右上角未来位置的分数改成负无穷，那些权重在 softmax 后变为 0。

### 缩放在这组形状里起什么作用

单个头的点积是 64 个数相加。若每个分量均值 0、方差 1 且相互独立，点积的方差就是 64，标准差是 8。相差一个标准差，softmax 的指数会差大约 `e^8`，分布几乎变成独热，梯度也接近 0。除以 `√64 = 8`，就是把这个方差拉回来。`d_k = 2` 的手算看不出这个现象。

## 读到后面再补的技能

| 读到 | 补什么 | 到什么程度就够 |
| --- | --- | --- |
| 第 3.5 节 位置编码 | 正弦、余弦，以及和角公式 `sin(a+b)`、`cos(a+b)` | 能接受「`PE(pos+k)` 可由 `PE(pos)` 线性表示」这句话从和角公式来 |
| 第 4 节 为何不用循环 | RNN 的递推 `h_t = f(h_{t-1}, x_t)`；卷积核宽度与路径长度 | 能说明样本内部为何必须按时间串行，以及路径 `O(n)` 与 `O(1)` 的差别。LSTM 四个门的公式可以先不背 |
| 第 5 节 训练 | 交叉熵、Adam 的名字、学习率先升后按步数平方根下降、dropout、标签平滑 | 能读学习率公式，并知道标签平滑会抬高困惑度、提高 BLEU。不必手推 Adam 的矩估计 |
| 第 6 节 实验 | 子词（BPE / word-piece）、开发集与测试集、困惑度、BLEU、束搜索、checkpoint 平均 | 能分清 25.8 是开发集、28.4 是测试集，以及束搜索不是训练损失 |

## 可以放到实现阶段

这些不影响把论文读通。开始写一个最小训练循环时再处理即可。

| 主题 | 那时要会的操作 |
| --- | --- |
| 张量的 batch 维 | 在上面的形状左边加一维 B，矩阵乘按最后两维进行 |
| 数值稳定的 softmax | 每行减去最大值再做 exp，避免溢出 |
| 掩码的写法 | 禁止位置加一个很大的负数，而不是在 softmax 之后硬改 |
| 共享嵌入的缩放 | 嵌入乘 `√d_model`，再和位置编码相加 |

## 读模型时先不用展开的内容

LSTM 门控的完整公式、成分句法的形式定义、RoPE、FlashAttention、KV cache、RLHF，以及 CUDA 层面的注意力实现，都是论文之后或工程侧的题目。第 6.3 节的句法分析只需要知道它是另一项序列到序列任务，F1 是分析器的分数。

## 一条够用的阅读顺序

先把最小集六项对上，再读论文第 3 节，并用 `n = 4` 的形状表逐行核对。第 4 节只带走「串行步数」和「路径长度」。第 5、6 节遇到 BLEU、束搜索和 BPE 时再补那一列。位置编码放到 3.5 节，和角公式够用即可。
