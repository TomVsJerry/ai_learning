# 矩阵与点积

阶段 1 的细读。过关标准：给定两个矩阵的行列数，能写出乘积的形状；能说明点积大表示两边方向更接近。

回到 [规划表](README.md)。下一阶段是 Softmax。

<a id="vector"></a>

## 向量：把几项特征排成一列数

一杯奶茶可以用三个数描写：甜度、冰度、茶香。小明的口味是

```text
小明 = [8, 2, 6]
```

意思是：很甜、不太冰、茶香中等。这个方括号里的一排数叫做向量。位置要固定：第一个数永远是甜度，第二个永远是冰度。把甜度和冰度对调，就是另一个人。

向量里的个数叫做维度。`[8, 2, 6]` 是 3 维。Transformer 里一个词的向量常常是 512 维，只是格子更多，算法一样。

<a id="dot"></a>

## 点积：对应位置相乘，再全部加起来

小红的口味是 `[7, 3, 5]`。两个人像不像，把同一项相乘，再相加：

```text
小明 · 小红 = 8×7 + 2×3 + 6×5
           = 56 + 6 + 30
           = 92
```

这个结果叫做点积。写法是中间一个点，或者写成 `q · k`。

再看一杯具体的饮料，珍珠奶茶 `[9, 1, 4]`（很甜、几乎不冰、有一点茶香）：

```text
小明 · 珍珠奶茶 = 8×9 + 2×1 + 6×4
               = 72 + 2 + 24
               = 98
```

98 比小明和小红的 92 更大：小明和这杯奶茶在「甜」这一项上同时很大，乘积就被拉高了。

点积回答的是：两边是不是在同样的特征上一起偏大。一起偏大，点积就大，表示方向更接近。

<a id="direction"></a>

## 方向：同向、垂直、反向

用平面上的两步路看得更干净。`[1, 0]` 是只向东走 1 步，`[0, 1]` 是只向北走 1 步。

| 两个方向 | 计算 | 点积 | 含义 |
| --- | --- | --- | --- |
| 东与东 | 1×1 + 0×0 | 1 | 完全同向 |
| 东与北 | 1×0 + 0×1 | 0 | 互不相干 |
| 东与西 | 1×(−1) + 0×0 | −1 | 正好相反 |

同向时点积为正，垂直时为 0，反向时为负。

长度也会把数放大。`[2, 0] · [2, 0] = 4`，方向和 `[1, 0] · [1, 0] = 1` 一样，都是正东，只是步子更长，点积更大。所以点积同时受两件事影响：方向像不像，以及两边的数有多大。注意力里后面要除以 `√d_k`，就是在处理「格子一多，点积就会变大」这件事。读到论文第 3.2 节再细看，这里先记住点积不是纯角度。

<a id="matrix"></a>

## 矩阵：把好几个向量叠成一张表

三杯饮料各是一个 3 维向量，叠起来就是一张表。每一行是一杯，每一列是一种特征。这张表叫做矩阵。

```text
         甜   冰   茶
珍珠奶茶  9    1    4
冰美式    1    2    8
柠檬茶    6    7    3
```

它有 3 行、3 列，形状写成 `3×3`。先说行，再说列。

两个人的口味也可以叠成 `2×3`：

```text
      甜   冰   茶
小明   8    2    6
小红   1    9    2
```

小红几乎不吃甜、很喜欢冰。

<a id="transpose"></a>

## 转置：行和列对调

转置就是把表翻转：原来的第 1 行变成第 1 列。记号是右上角一个 T，比如 `Kᵀ`。

饮料表转置之后：

```text
    珍珠  冰美式  柠檬茶
甜    9     1      6
冰    1     2      7
茶    4     8      3
```

形状从 `3×3` 仍是 `3×3`，因为本来就是方的。如果原来是 `2×3`，转置后是 `3×2`。行数和列数互换。

<a id="matmul"></a>

## 矩阵乘法：每一行和每一列做点积

想知道每个人更贴哪一杯，就让每个人的口味向量去和每一杯做点积。矩阵乘法就是把这件事一次做完。

结果表的第 i 行、第 j 列 = 左边矩阵的第 i 行 · 右边矩阵的第 j 列。

左边用口味 `Q`（2 行 3 列）。右边必须是「每一列是一杯饮料」。那正是上面的转置，记成 `Kᵀ`。于是计算的是 `Q Kᵀ`。

小明那一行对三杯：

```text
小明 · 珍珠 = 8×9 + 2×1 + 6×4 = 98
小明 · 美式 = 8×1 + 2×2 + 6×8 = 60
小明 · 柠檬 = 8×6 + 2×7 + 6×3 = 80
```

小红那一行：

```text
小红 · 珍珠 = 1×9 + 9×1 + 2×4 = 26
小红 · 美式 = 1×1 + 9×2 + 2×8 = 35
小红 · 柠檬 = 1×6 + 9×7 + 2×3 = 75
```

写成结果矩阵：

```text
        珍珠   美式   柠檬
小明     98     60     80
小红     26     35     75
```

小明的最高分在珍珠奶茶（98），因为他和这杯都甜。小红的最高分在柠檬茶（75），因为她在乎冰，柠檬茶的冰度是 7。这张 `2×3` 的分数表，就是注意力里 softmax 之前的那张打分表：每个查询对每个键打一个分。

<a id="shape"></a>

## 形状规则：里面的两个数必须一样

`Q` 是 `2×3`，`Kᵀ` 是 `3×3`。乘的时候把它们写成

```text
(2 × 3) × (3 × 3) = 2 × 3
         ↑   ↑
       这两个必须相等
```

相等的那一维是「特征个数」：两边都是甜、冰、茶这 3 项，点积才对得齐。外面剩下的两个数是结果的形状：2 个人、3 杯饮料，所以结果是 `2×3`。

一般规则：

```text
(m × n) × (n × p) = m × p
```

中间的 `n` 被点积「消耗」掉了。

如果忘记转置，拿 `2×3` 直接乘 `3×3` 的饮料原表，中间是 3 对 3，形状能乘，但每一列不再是「一杯饮料的三项特征」，乘出来的数没有「人和饮料的匹配分」这个含义。转置的作用是把「每一行一个对象」转成「每一列一个对象」，好让行和列做点积。

中间对不齐就不能乘。`2×3` 乘 `2×3` 时，中间是 3 对 2，特征数目不同，对应位相乘无从做起。

<a id="projection"></a>

## 用矩阵把旧特征混成新特征

矩阵乘一个向量，是按列上的权重把旧特征混合成新特征。例如想从甜、冰、茶算出两个新分数：

```text
清爽 = 0×甜 + 1×冰 + 0.5×茶
甜腻 = 1×甜 + 0×冰 + 0×茶
```

权重表 `W` 是 `3×2`：3 个旧特征，2 个新特征。

```text
      清爽   甜腻
甜      0     1
冰      1     0
茶     0.5    0
```

小明 `[8, 2, 6]` 乘这张表：

```text
清爽 = 8×0 + 2×1 + 6×0.5 = 5
甜腻 = 8×1 + 2×0 + 6×0   = 8
```

形状是 `(1×3) × (3×2) = 1×2`。人从「甜、冰、茶」变成了「清爽、甜腻」。Transformer 里的 `W^Q` 就是这种混合：把 512 维投到一个头所用的 64 维。`512×64` 的意思是 512 个旧特征、64 个新特征。

<a id="qk"></a>

## 对上论文里的 QKᵀ

把「人」换成「词」，把「甜、冰、茶」换成模型学出来的特征，上面的乘法就是

```text
Attention 里的打分表 = Q Kᵀ
```

设一句话有 `n` 个词，每个词的查询是 `d_k` 维：

| 量 | 形状 | 对应这里的例子 |
| --- | --- | --- |
| Q，每个词一个查询 | n × d_k | 2 个人 × 3 项特征，即 2×3 |
| K，每个词一个键 | n × d_k | 若饮料也按行放，是「对象 × 特征」 |
| Kᵀ | d_k × n | 特征 × 对象，每一列可以和 Q 的一行做点积 |
| QKᵀ | n × n | 每个词对每个词一个分数；例子里是人×饮料，所以是 2×3 |

论文里的句子是词对词，查询个数和键个数都是 `n`，所以 `QKᵀ` 是 `n×n`。例子里人和饮料数量不同，结果才是 `2×3`。形状规则相同。

## 过关自测

先盖住答案。

1. 计算 `[3, 1, 4] · [2, 5, 1]`。
2. `(5×8)` 乘 `(8×2)`，结果是什么形状？`(5×8)` 能乘 `(2×8)` 吗？
3. 下面这张 `Q` 是 `2×2`，`K` 也是 `2×2`。写出 `Kᵀ`，再算出 `QKᵀ`。

```text
Q = [ 1  0 ]
    [ 0  1 ]

K = [ 2  3 ]
    [ 4  0 ]
```

答案：

1. `3×2 + 1×5 + 4×1 = 6 + 5 + 4 = 15`。
2. 结果是 `5×2`。`(5×8)` 和 `(2×8)` 中间是 8 对 2，不能乘。先把右边转置成 `(8×2)` 就可以。
3. `Kᵀ` 是

```text
[ 2  4 ]
[ 3  0 ]
```

`QKᵀ` 是

```text
[ 1×2+0×3    1×4+0×0 ]   [ 2  4 ]
[ 0×2+1×3    0×4+1×0 ] = [ 3  0 ]
```

`Q` 正好是单位阵，乘出来等于 `Kᵀ`。结果形状是 `2×2`。
