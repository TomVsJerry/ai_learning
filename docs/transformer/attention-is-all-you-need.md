## 一篇把序列模型改成纯注意力的论文

2017 年 6 月，Ashish Vaswani、Noam Shazeer、Niki Parmar、Jakob Uszkoreit、Llion Jones、Aidan N. Gomez、Łukasz Kaiser 和 Illia Polosukhin 在 arXiv 放出 Transformer。八位作者同等贡献，署名顺序随机。除 Gomez（多伦多大学，工作完成于 Google Brain）和 Polosukhin（工作完成于 Google Research）外，作者当时在 Google Brain 或 Google Research。会议版本是 NeurIPS 2017。

当时最强的序列到序列模型是带注意力的循环网络，或用卷积代替循环的 ByteNet、ConvS2S。注意力已经存在：Bahdanau 等人 2014 年用它连接编码器和解码器。这篇论文把循环和卷积整个去掉，编码器和解码器只堆自注意力和逐位置前馈网络。

论文自己的主张：纯注意力模型可以在样本内部并行，远距离依赖的路径长度是常数，翻译质量超过当时包括集成在内的最好结果，训练时间也短得多。base 模型在 8 张 P100 上训练约 12 小时。

## 循环把序列位置绑在计算时间上

循环网络按位置生成隐状态：`h_t` 依赖 `h_{t-1}` 和当前位置的输入。训练一个句子时，这些步骤必须串行。句子一长，样本内部就无法并行，显存又限制了跨样本的批大小。LSTM 和 GRU 是当时机器翻译与语言建模的主流，注意力也多半加在循环网络上面。

卷积模型（Extended Neural GPU、ByteNet、ConvS2S）可以同时计算所有位置，但两个位置之间的计算步数仍随距离增长。普通卷积大约线性增长，ByteNet 的膨胀卷积大约按对数增长。Transformer 把任意两个位置的路径长度降为常数。代价是注意力在做加权平均，有效分辨率下降；作者用多头注意力来缓解。

### 选择层类型时的三个标准

第 4 节比较的是：把长度 `n`、维度 `d` 的序列映射到另一条等长序列时，每层要多少计算、最少要多少串行步，以及任意两个位置之间的最长路径。路径越短，梯度越容易把远距离依赖学出来。

| 层类型 | 每层复杂度 | 最少串行步 | 最长路径 |
| --- | --- | --- | --- |
| 自注意力 | O(n² · d) | O(1) | O(1) |
| 循环层 | O(n · d²) | O(n) | O(n) |
| 卷积层 | O(k · n · d²) | O(1) | O(log_k n) |
| 局部自注意力 | O(r · n · d) | O(1) | O(n / r) |

来源：论文 Table 1。`n` 为序列长度，`d` 为表示维度，`k` 为卷积核宽度，`r` 为局部自注意力的邻域大小。

句子的子词长度通常小于表示维度（base 模型 `d = 512`）。此时自注意力每层比循环层更省。核宽小于 `n` 的一层卷积连不上所有位置对：连续卷积要堆大约 `n/k` 层，膨胀卷积大约 `log_k(n)` 层。可分离卷积能把复杂度降到 `O(k · n · d + n · d²)`；即便 `k = n`，也只和「一层自注意力加一层逐位置前馈」相当，而这正是 Transformer 的一个块。

若序列极长，可把注意力限制在半径 `r` 的邻域里。复杂度变为 `O(r · n · d)`，最长路径变为 `O(n / r)`。论文把图像、音频、视频列成后续工作，没有在这篇里做实验。

## 仍是编码器—解码器，中间换成注意力块

编码器把源符号 `(x_1, …, x_n)` 映射成连续表示 `z`。解码器自回归地一次吐出一个目标符号：生成第 `i` 个词时，只能使用已经生成的前缀。Transformer 的两边都是「多头注意力 + 逐位置全连接」的堆叠。base 模型每边 `N = 6` 层，所有子层和嵌入的输出维度都是 `d_model = 512`，这样残差才能直接相加。

编码器，自下而上：

1. 源语言 token（BPE 或 word-piece 子词）。
2. 词嵌入 + 位置编码，两者相加，只在栈底做一次。
3. 重复 6 次：多头自注意力（Q、K、V 都来自上一层输出），然后逐位置前馈网络（内层宽度 2048，中间是 ReLU）。
4. 编码器记忆：整层输出交给解码器，作为 K 和 V。

解码器，自下而上：

1. 已生成的目标 token，嵌入整体右移一位。
2. 词嵌入 + 位置编码，与编码器、softmax 前的线性层共享权重。
3. 重复 6 次：掩码多头自注意力（当前位置只能看自己和左侧），编码器—解码器注意力（Q 来自解码器，K、V 来自编码器记忆），逐位置前馈网络（形状与编码器相同，参数各层独立）。
4. 线性层 + softmax，预测下一个 token 的分布。

每个子层的实际输出是 `LayerNorm(x + Sublayer(x))`。归一化用的是 Ba、Kiros 与 Hinton 2016 年的 Layer Normalization，残差来自 He 等人 2016 年的形式。

```text
每个子层：  LayerNorm(x + Sublayer(x))
前馈网络：  FFN(x) = max(0, x W1 + b1) W2 + b2
位置编码：  PE(pos, 2i)   = sin(pos / 10000^(2i / d_model))
            PE(pos, 2i+1) = cos(pos / 10000^(2i / d_model))
```

前馈网络对每个位置单独作用，同一层内各位置共享参数，层与层之间参数不同。输入输出维度 512，隐藏层 2048。它等价于两个核宽为 1 的卷积。

词嵌入是学出来的。源嵌入、目标嵌入，以及 softmax 前的线性变换，三处共用同一张权重矩阵，嵌入侧再乘上 `√d_model`。论文写明了这个缩放，没有展开动机；和 Press 与 Wolf 2016 一样，共享是为了让输入输出待在同一套向量空间里。

模型里没有循环也没有卷积，顺序必须另注入。正弦位置编码和词嵌入同维，直接相加。波长从 `2π` 按几何级数增到 `10000 · 2π`。作者的假设是：对固定偏移 `k`，`PE_{pos+k}` 可以写成 `PE_pos` 的线性函数，因此相对位置容易被注意力利用；正弦形式还可能外推到训练时没见过的长度。开发集上，把它换成可学习的位置嵌入，困惑度同为 4.92，BLEU 25.7，正弦版本是 25.8。论文据此保留正弦形式。外推能力本身没有在这篇里单独测量。

## 查询对一组键打分，再对值做加权和

注意力把查询 query 和一组键值对 key / value 映射成一个输出。输出是值向量的加权和，权重由查询和对应键的相容度决定。论文选用缩放点积，而不是 Bahdanau 的加性注意力。两者复杂度同级，点积可以落到高度优化的矩阵乘法上，更快也更省显存。

```text
Attention(Q, K, V) = softmax(Q Kᵀ / √d_k) V
```

`Q` 的每一行是一个查询，`K`、`V` 的每一行是一个键和值。键的维度是 `d_k`，值的维度是 `d_v`。先算所有查询和所有键的点积，除以 `√d_k`，再沿键的方向做 softmax。

### 为什么要除以 √d_k

`d_k` 较小时，加性注意力和未缩放的点积差不多；`d_k` 变大后，未缩放的点积会输给加性注意力。作者的解释是：若 `q`、`k` 的分量独立、均值 0、方差 1，点积的方差就是 `d_k`。方差一大，softmax 进入梯度几乎为 0 的饱和区。除以 `√d_k` 把方差拉回 1 附近。

下面是一组手算，只用来看公式怎么走，不是论文里的权重。查询是 sat，`d_k = 2`，三个键的点积取 1.0、0.0、0.8。

| 键 | 点积 | 除以 √2 | softmax 权重 |
| --- | --- | --- | --- |
| The | 1.0 | 0.707 | 0.424 |
| cat | 0.0 | 0.000 | 0.209 |
| sat | 0.8 | 0.566 | 0.368 |

不缩放时权重约为 0.457、0.168、0.374。`d_k = 2` 时两者差别不大。`d_k = 64` 时点积标准差约为 8，相差一个标准差就会让 softmax 权重差大约 `e^8 ≈ 3000` 倍。

### 多头：分到不同子空间里各看一遍

```text
MultiHead(Q, K, V) = Concat(head_1, …, head_h) W^O
head_i = Attention(Q W_i^Q, K W_i^K, V W_i^V)
```

单个头在全维度上做平均，会把不同子空间的信息混在一起。论文把 Q、K、V 用 `h` 套不同的线性投影投到较低维度，并行做 `h` 次注意力，拼接后再乘 `W^O`。base 模型 `h = 8`，`d_k = d_v = 512 / 8 = 64`。因为每头更窄，总计算量和一个全维度单头接近。投影矩阵的形状是 `W_i^Q`、`W_i^K` 为 `512×64`，`W_i^V` 为 `512×64`，`W^O` 为 `512×512`。

### 同一套多头，在模型里接三次

| 位置 | Q 的来源 | K、V 的来源 | 可见范围 |
| --- | --- | --- | --- |
| 编码器自注意力 | 编码器上一层 | 同一序列的上一层 | 所有源位置 |
| 解码器自注意力 | 解码器上一层 | 解码器已生成的前缀 | 当前位置及其左侧 |
| 编码器—解码器注意力 | 解码器上一层 | 编码器栈的最终输出 | 所有源位置 |

解码器要保持自回归。实现上是在 softmax 之前，把「未来位置」的分数设成负无穷，那些位置的权重就会变成 0。再加上目标嵌入右移一位，位置 `i` 的预测只依赖已知的、下标小于 `i` 的输出。编码器—解码器注意力就是传统序列到序列模型里的那条跨接，只是两边都不再是循环层。

作者查看了编码器第 5 层（共 6 层）的头。不少头会从动词 making 连到远处的 more difficult，把 making … more difficult 配完整。另有头专门处理 its 的指代，分布很尖。不同头学到的模式不一样，有的接近句法结构。论文把这当作自注意力可解释性的旁证，放在附录，不是定量实验。

## 分数来自一套写明的训练配方

第 6 节的 BLEU 不是架构草图单独产生的。数据规模、批的定义、学习率日程、dropout、标签平滑和解码时的 checkpoint 平均都写在第 5、6 节里。

英译德用 WMT 2014，约 450 万句对，字节对编码，源和目标共用约 37000 个 token。英译法用 WMT 2014 的 3600 万句，32000 词片词汇表。一个训练 batch 大约含 25000 个源 token 和 25000 个目标 token，按相近句长组批。

一台机器、8 张 NVIDIA P100。base 每步约 0.4 秒，10 万步，约 12 小时。big 每步约 1.0 秒，30 万步，3.5 天。big 的宽度是 `d_model = 1024`，`d_ff = 4096`，`h = 16`，英译德 dropout 0.3。

```text
lrate = d_model^(−0.5) · min( step^(−0.5), step · warmup_steps^(−1.5) )
```

优化器是 Adam，`β1 = 0.9`，`β2 = 0.98`，`ε = 10^(−9)`。`β2` 比常见的 0.999 更小。学习率先按步数线性升高，warmup 之后按步数的平方根反比下降。两条曲线在 `warmup_steps` 处相遇。论文取 `warmup_steps = 4000`。

base 模型（`d_model = 512`）按该公式算出的学习率：

| 步数 | 学习率 |
| --- | --- |
| 500 | 8.73×10⁻⁵ |
| 1000 | 1.75×10⁻⁴ |
| 2000 | 3.49×10⁻⁴ |
| 4000 | 6.99×10⁻⁴ |
| 8000 | 4.94×10⁻⁴ |
| 20000 | 3.13×10⁻⁴ |
| 50000 | 1.98×10⁻⁴ |
| 100000 | 1.40×10⁻⁴ |

峰值在第 4000 步。

| 手段 | base 取值 | 加在哪里 |
| --- | --- | --- |
| 残差 dropout | 0.1 | 每个子层输出，加回输入并做 LayerNorm 之前 |
| 嵌入 dropout | 0.1 | 词嵌入与位置编码相加之后，编码器和解码器都加 |
| 标签平滑 | ε = 0.1 | 训练目标分布。困惑度会变差，准确率和 BLEU 会变好 |

big 模型在英译德上把 dropout 提到 0.3。英译法的 big 模型例外，仍用 0.1。论文没有使用额外的权重衰减项。

头数与开发集 BLEU（总计算量保持大致不变）：1 头 24.9，4 头 25.5，8 头 25.8，16 头 25.8，32 头 25.4。

论文对这张表的读法是：单头比该组最好设置低 0.9 BLEU，头太多也会掉；缩小 `d_k` 会伤质量，说明点积这种相容度并不宽裕，更复杂的打分函数或许还有空间；更大的模型总体更好；dropout 对抑制过拟合帮助很大；正弦位置编码和可学习位置嵌入几乎相同。

表内还有两处值得单独看。去掉 dropout 后 BLEU 掉到 24.6，是正则项里最陡的一档。去掉标签平滑后困惑度最好（4.67），BLEU 只有 25.3，平滑到 0.1 时 BLEU 回到 25.8、困惑度升到 4.92。另外，`d_ff = 4096` 的 90M 模型开发集 BLEU 为 26.2，高于 `d_model = 1024`、168M 参数那一档的 26.0。层数加到 8 并没有继续抬高 BLEU。

## 论文停在哪里

结论把 Transformer 定义为第一个完全靠注意力做序列到序列的模型：多头自注意力换掉编码器—解码器里常见的循环层。翻译上它训练得更快，英译德和英译法都达到当时的新水平，英译德还超过了已发表的集成系统。

作者列出的下一步是三件事：把模型用到文本以外的输入输出；研究局部、受限的注意力，以便处理图像、音频和视频这类长序列；让生成过程少一些串行。这些都停留在计划，不是这篇论文的实验结果。

### 读数时容易接错的地方

| 容易混的两件事 | 论文里的实际差别 |
| --- | --- |
| 注意力是不是这篇发明的 | 跨编码器与解码器的注意力来自更早的神经翻译。这篇拿掉的是循环和卷积 |
| 28.4 和 25.8 | 28.4 是 big、测试集、做了 checkpoint 平均；25.8 是 base、开发集、没有平均 |
| 英译法 base 的 38.1 | 低于先前单模型。41.8 来自 big，且该任务的 big 使用 dropout 0.1 |
| 开发集上 N = 8 更好 | 困惑度更低，BLEU 为 25.5，低于 6 层的 25.8 |
| 正弦编码已被证明能外推 | 开发集上与可学习嵌入几乎相同。外推是作者选择正弦的理由，不是已报告的测量 |

### 论文发表之后

下面不是论文中的主张。编码器堆叠后来成为 BERT 一类双向预训练的骨架，解码器堆叠成为 GPT 一类自回归语言模型的骨架，完整的编码器—解码器则留在 T5 这类序列到序列模型里。视觉 Transformer 把图像切块后送进同一类自注意力。第 4 节那个半径 `r` 的局部注意力，是后来稀疏、滑窗注意力要处理的同一个 `n²` 问题。
