## 线性层：同一套混合规则，再加一个底分

小明的口味仍是甜、冰、茶 `[8, 2, 6]`。沿用上一份笔记里的混合：

```text
清爽 = 0×甜 + 1×冰 + 0.5×茶
甜腻 = 1×甜 + 0×冰 + 0×茶
```

小明得到清爽 5、甜腻 8。这只是 `xW`：旧特征乘权重表。

线性层再加一项底分 `b`，和输入无关。设清爽的底分是 1，甜腻的底分是 0：

```text
清爽 = 0×甜 + 1×冰 + 0.5×茶 + 1
甜腻 = 1×甜 + 0×冰 + 0×茶   + 0
```

小明变成清爽 6、甜腻 8。底分的含义是：就算甜、冰、茶全是 0，清爽仍从 1 起步。公式写成

```text
y = xW + b
```

`W` 决定旧特征怎样混进新特征，`b` 是每个新特征自己的起点。同一层里，每个人、每一杯都用同一张 `W` 和同一个 `b`。换的是输入 `x`，不换混合规则。

热浓茶 `[0, −6, 2]`（不甜、很烫所以冰度是负的、有一点茶香）走同一套规则：

```text
清爽 = 0×0 + 1×(−6) + 0.5×2 + 1 = −4
甜腻 = 1×0 + 0×(−6) + 0×2   + 0 = 0
```

形状仍是 `(1×3) × (3×2) = 1×2`，再加一个 2 维的底分。输入是 3 个数，输出是 2 个数。

<a id="bias"></a>

## 底分 b：所有输入都加的同一笔固定分

`W` 会看这杯饮料的甜、冰、茶。`b` 不看。不管送来的是小明、热浓茶，还是全是 0 的空杯，清爽都先加 1，甜腻都先加 0。换输入，`b` 这一笔不变。

可以把它想成考试的基础分。卷面题按答题情况给分，那是 `xW`。另外每人再加 1 分出勤分，那是 `b`。答得再差，出勤分也在；答得再好，出勤分也不多给。

把小明、空杯、热浓茶并排看：

| 输入 | xW（按味道算出来的） | 加上 b | 线性层输出 |
| --- | --- | --- | --- |
| 空杯 `[0, 0, 0]` | `[0, 0]` | `+ [1, 0]` | `[1, 0]` |
| 小明 `[8, 2, 6]` | `[5, 8]` | `+ [1, 0]` | `[6, 8]` |
| 热浓茶 `[0, −6, 2]` | `[−5, 0]` | `+ [1, 0]` | `[−4, 0]` |

三行里加的都是 `[1, 0]`。小明比空杯多出来的 `[5, 8]`，全部来自味道，不是来自底分。底分只把每一行整体平移了一下。

没有 `b` 时，输入全是 0，输出也必须是 0。有了 `b`，输出可以停在一个默认值上。清爽的默认是 1，甜腻的默认是 0。两个新特征各有自己的那一格底分，所以 `b` 的长度等于输出的格数，这里是 2，不是输入的 3。

底分也会决定后面 ReLU 开不开。热浓茶的清爽是 −5，加上 1 仍是 −4，ReLU 之后仍是 0。如果把清爽的底分改成 6：

```text
热浓茶清爽 = −5 + 6 = 1
```

ReLU 之后清爽变成 1，这项就留着参加后面的混合。同一杯茶，只改底分，就能把一项从关掉变成开着。`W` 管「按味道怎么算」，`b` 管「算完之后整体抬高还是压低」。

同一层里所有位置共用一个 `b`。句子里每个词都加同一笔，不会出现「这个词底分 1、那个词底分 3」。要让不同词得到不同输出，靠的是各自的 `x` 不同。

论文注意力公式里的 `W^Q`、`W^K`、`W^V` 只写了 `W`，没有 `b`。前馈网络两边都写了底分：`b1` 和 `b2`。读公式时按原文：注意力投影先当没有底分，前馈网络才有。

<a id="relu"></a>

## ReLU：负数一律当成「这项没有」

清爽 −4 很难解释成「倒出负的 4 毫升清爽」。ReLU 的规则只有一条：小于 0 的数改成 0，大于 0 的数原样留下。

```text
ReLU(t) = max(0, t)
```

热浓茶的 `[−4, 0]` 变成 `[0, 0]`。小明的 `[6, 8]` 两个都是正的，经过 ReLU 仍是 `[6, 8]`。

它按每个数单独处理。一项是负的，只把那一项清掉，旁边的正数不动。

前馈网络把线性层和 ReLU 串起来。论文里的写法是

```text
FFN(x) = max(0, x W1 + b1) W2 + b2
```

先做一次线性层，把负数清成 0，再做第二次线性层。用一个很小的第二次来看差别。第二次只出一格「推荐分」：`0.5×清爽 + 1×甜腻`，底分 0。

| 输入 | 第一次线性层 | 经过 ReLU | 推荐分 |
| --- | --- | --- | --- |
| 小明 `[8, 2, 6]` | `[6, 8]` | `[6, 8]` | 0.5×6 + 8 = 11 |
| 热浓茶 `[0, −6, 2]` | `[−4, 0]` | `[0, 0]` | 0 |

热浓茶如果不做 ReLU，推荐分是 `0.5×(−4) = −2`。负的清爽会把推荐分往下拉。ReLU 之后，清爽这项是关掉的，它不再参与后面的混合。

两次线性层中间如果没有 ReLU，整段仍然可以收成一次 `y = xW + b`。小明那条就是

```text
推荐 = 1×甜 + 0.5×冰 + 0.25×茶 + 0.5
     = 8 + 1 + 1.5 + 0.5
     = 11
```

中间的「清爽、甜腻」可以消掉。ReLU 一裁负数，这种合并就不再成立，中间哪些特征开着，会改变后面的混合。

## 词嵌入：编号去表里查一行

到这里为止，甜、冰、茶都是直接写好的数。模型读到的词是编号，不是这三格。

词表可以编成：

| 编号 | 词 |
| --- | --- |
| 0 | 珍珠 |
| 1 | 美式 |
| 2 | 柠檬 |

嵌入表的每一行就是这个词的向量。行号就是词的编号：

```text
0  珍珠  [9, 1, 4]
1  美式  [1, 2, 8]
2  柠檬  [6, 7, 3]
```

句子「珍珠 柠檬」先变成编号 `[0, 2]`。查表得到两行：`[9, 1, 4]` 和 `[6, 7, 3]`。查表不做加减，编号 0 就拿第 0 行。

这张表是参数，和 `W` 一样会在训练里被修改。上面的甜、冰、茶只是为了手算借用的名字。真实模型里一行有 512 个数，每一格代表什么没有人事先规定，训练自己把有用的方向分开。

查表也可以写成一次矩阵乘法。用只有一个 1 的向量表示「是哪个词」：珍珠是 `[1, 0, 0]`，乘嵌入表就取出第 0 行 `[9, 1, 4]`。所以嵌入是一种特殊的线性层：输入表示词的编号，通常不加底分 `b`。

<a id="where"></a>

## 它们在 Transformer 里各做一处

注意力里的三套投影 `W^Q`、`W^K`、`W^V` 是线性层：把每个词的 512 个数混成这个头用的 64 个数。论文的注意力公式里只写了 `W`，没有写底分 `b`。

每个词自己的前馈网络才是带 ReLU 的那两段线性层。同一层里所有词共用同一套 `W1`、`b1`、`W2`、`b2`。词和词的差别来自各自的输入向量，不来自各用一张表。

输出端还要把向量变回「每个词一个分数」，再做 softmax。论文让这最后一次线性层和嵌入表共用同一套权重。直观地说：一个词在表里的那一行，既是「读到这个词时取出的向量」，也是「输出向量和它点积，用来判断像不像这个词」的那一行。点积大，这个词的分数就高。

## 过关自测

先盖住答案。`W` 仍是上面那张：清爽用 `[0, 1, 0.5]`，甜腻用 `[1, 0, 0]`，底分是 `[1, 0]`。

1. 输入 `[0, 0, 0]`，线性层输出是什么？这说明 `b` 在做什么？
2. 对 `[−2, 3, −0.5]` 做 ReLU。
3. 词表编号 1 是美式。嵌入表如上。句子里出现编号 1 时，取出哪一行？

答案：

1. `[1, 0]`。输入全是 0 时，`xW` 是 0，输出就是底分。清爽从 1 起步，甜腻从 0 起步。
2. `[0, 3, 0]`。负数变成 0，3 保持 3。
3. 第 1 行 `[1, 2, 8]`。编号直接对应行号。
