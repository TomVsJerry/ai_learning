# 残差与 LayerNorm

阶段 4 的细读。过关标准：会写 `LayerNorm(x + Sublayer(x))`，并能说明相加的两个向量必须一样长。

## 残差：在原来那一杯上做修改

小明原来的甜、冰、茶是

```text
x = [8, 2, 6]
```

一个子层（注意力或前馈网络）算出一份修改量。这里把它选成

```text
Sublayer(x) = [1, 3, −2]
```

含义是：甜加 1，冰加 3，茶减 2。残差把修改加回原来那一杯，而不是用修改量替换原来那一杯：

```text
x + Sublayer(x) = [8+1, 2+3, 6+(−2)] = [9, 5, 4]
```

子层如果算出全 0，加回去仍是 `[8, 2, 6]`。这一层等于没改配方，原来的甜、冰、茶原样留下。堆 6 层时，每一层都可以选择只改一点点，或这一层先不改。

直接用子层的输出替换 `x` 时，下一层只能看见 `[1, 3, −2]`，原来的 `[8, 2, 6]` 已经不在这个向量里。相加之后，下一层看见的是改过的一杯 `[9, 5, 4]`，原来的味道还在里面。

两个向量要一样长才能逐格相加。`[8, 2, 6]` 可以加 `[1, 3, −2]`，不能加 `[1, 3]`。论文里每个子层的输出宽度都是 `d_model = 512`，就是为了和输入的 512 格对齐。

## LayerNorm：把这一杯的三格拉回同一把尺子

相加之后是 `[9, 5, 4]`。三格的平均是

```text
(9 + 5 + 4) / 3 = 6
```

每一格减去 6：

```text
[9−6, 5−6, 4−6] = [3, −1, −2]
```

这三格的起伏用标准差量。平方平均是 `(9 + 1 + 4) / 3 = 14/3`，标准差约 2.160。再逐格除以它：

```text
3    / 2.160 ≈  1.389
−1   / 2.160 ≈ −0.463
−2   / 2.160 ≈ −0.926
```

三格平均约为 0，起伏约为 1。甜仍是三者里最高的，茶仍是最低的，只是整体高低和拉开的幅度被收成统一尺度。公式是

```text
LayerNorm(y) = (y − 平均) / 标准差
```

这里的平均和标准差只在这一杯的几格之间算。另一杯 `[100, 2, 6]` 自己算自己的平均和标准差，不会用小明这杯的 6 和 2.160。句子里每个词各做一次。

再看一杯数字特别大的：`[100, 2, 6]`。若不做这一步，后面的点积会被 100 主导，2 和 6 几乎不起作用。LayerNorm 之后三格大约是 `[1.413, −0.751, −0.663]`，最高的仍是第一格，但大小回到和别的杯子相近的范围。下一层看到的是「哪一格相对更高」，而不是「这杯的数字整体特别大」。

## 缩放和偏移：拉平之后还可以再拉开

真正的 LayerNorm 在除完标准差之后，还有一组可学习的缩放 `γ` 和偏移 `β`，每一格各有一个：

```text
结果 = γ × (y − 平均) / 标准差 + β
```

`γ` 和 `β` 的长度等于向量长度。上面算出的 `[1.389, −0.463, −0.926]` 对应 `γ = [1, 1, 1]`、`β = [0, 0, 0]`。

若甜这一格学到 `γ = 2`、`β = 1`，另外两格仍是 `γ = 1`、`β = 0`：

```text
甜 = 2×1.389 + 1 ≈ 3.778
冰 = 1×(−0.463) + 0 ≈ −0.463
茶 = 1×(−0.926) + 0 ≈ −0.926
```

归一化先把尺子统一，`γ` 和 `β` 再允许模型把某一格重新拉大或挪开。

标准差为 0 时不能除。三格都是 5 时，平均是 5，每格减完都是 0。实现里在标准差平方上加一个很小的数，常见是 `10^(−5)`，避免除以 0。减完已经是 0，结果就由 `β` 决定。

## 论文里的顺序

每个子层外面都是先相加，再做 LayerNorm：

```text
LayerNorm(x + Sublayer(x))
```

用上面的数就是：输入 `[8, 2, 6]`，子层修改 `[1, 3, −2]`，相加得 `[9, 5, 4]`，再归一化成约 `[1.389, −0.463, −0.926]`（`γ = 1`、`β = 0` 时）。注意力子层和前馈子层都套这一层。

## 过关自测

1. `x = [8, 2, 6]`，子层输出 `[0, 0, 0]`。残差相加的结果是什么？
2. `[8, 2, 6]` 能和 `[1, 3]` 相加吗？
3. `[4, 4, 4]` 减去自己的平均之后是什么？

答案：

1. `[8, 2, 6]`。修改量是 0，原来的三格原样留下。
2. 不能。两边分别是 3 格和 2 格，没有逐格对应。
3. `[0, 0, 0]`。平均是 4，每一格都正好等于平均。
