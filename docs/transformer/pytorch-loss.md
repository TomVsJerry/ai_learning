# 损失函数：把输出和答案收成一个数

前向结束时，网络交出一排数。损失函数把这排数和标签比一比，得到**一个数**。这个数越小，输出越接近答案。`loss.backward()` 按这个数对每个参数的变化率去填梯度，`step()` 再改 `W` 和 `b`。

三种损失的公式不同，所以同一个输出会得到不同的这一个数，梯度的方向和大小也不同。对照脚本是 [losses.py](../../examples/pytorch/lesson2/losses.py)。

<a id="mse"></a>

## 均方误差 `MSELoss`

每个预测减去对应的答案，平方，再取平均。

```text
预测 0.8，答案 1.0    (0.8 − 1.0)² = 0.04
预测 0.2，答案 0.0    (0.2 − 0.0)² = 0.04
平均                  0.04
```

预测和答案的形状相同，格子一一对应。网上那个小例子在最后一层后面先做了 Sigmoid，输出落在 0 和 1 之间，答案也是 0 或 1，再用这个平方差。

<a id="ce"></a>

## 交叉熵 `CrossEntropyLoss`

网络交出的是每一类一个分数，还没变成百分比。标签是类别编号。小明的分数是 `[3.2, −0.7]`，标签是 0（喜欢在第 0 格）。

损失内部先做 Softmax，再取正确那一格的负对数：

```text
百分比 ≈ [0.980160, 0.019840]
损失 = −ln(0.980160) = 0.020040
```

分数的形状是 `(批量, 类别数)`，标签的形状是 `(批量,)`，里面是整数。读数字项目用的就是这一种：10 个分数，标签是 0～9。`forward` 里不再写 Softmax，百分比由这个损失在内部算。

<a id="bce"></a>

## 二分类 `BCEWithLogitsLoss`

每个输出是一个分数，对应一个「是 / 否」。标签是 0 或 1 的小数，形状和分数相同。损失内部先做 Sigmoid，把分数收进 0 和 1，再按这一格是不是 1 来取负对数。

分数 `3.2`、标签 `1`：

```text
Sigmoid(3.2) = 0.960834
损失 = −ln(0.960834) = 0.039953
```

分数 `−0.7`、标签 `0`：

```text
Sigmoid(−0.7) = 0.331812
这一格「否」的百分比 = 1 − 0.331812 = 0.668188
损失 = −ln(0.668188) = 0.403186
```

两格平均是 `0.221570`。公式是

```text
−[ y ln p + (1 − y) ln(1 − p) ]
```

`p` 是 Sigmoid 之后的数，`y` 是 0 或 1。`y = 1` 时只留下 `−ln p`；`y = 0` 时只留下 `−ln(1 − p)`。

线性层的分数直接送进这个损失。Sigmoid 写在损失内部。

<a id="role"></a>

## 在网络里起的作用

训练循环里它占这一行：

```python
y_pred = model(x)            # 输出
loss = criterion(y_pred, y)  # 一个数
loss.backward()              # 这个数对每个参数的变化率
optimizer.step()             # 按变化率改 W、b
```

损失不增加新的层。它决定训练要缩小的是哪一个数，因此也决定梯度。

同一点上，两种算法的变化率可以不同。预测概率是 0.5、答案是 1 时，平方差是 `(0.5 − 1)² = 0.25`。概率这一格的变化率是 `2×(0.5 − 1) = −1`：概率加大，损失下降。

二分类损失若收到的是分数 0（Sigmoid 之后也是 0.5）、答案是 1，损失是 `−ln(0.5) = 0.693147`。分数这一格的变化率是 `0.5 − 1 = −0.5`。方向同样是把分数加大，一步的大小和均方误差不同。

<a id="meaning"></a>

## 交叉熵在算什么

Softmax 之后，每一类有一个百分比，加起来是 1。答案也可以写成这样一排百分比：喜欢是 `[1, 0]`，意思是第 0 格占满 100%，第 1 格是 0。

交叉熵用答案那一排当权重，去加每一格的 `−ln(预测百分比)`：

```text
答案权重 × (−ln 预测百分比)，再全部加起来
```

小明的预测百分比是 `[0.980160, 0.019840]`，答案权重是 `[1, 0]`：

```text
第 0 格  1 × (−ln 0.980160) = 0.020040
第 1 格  0 × (−ln 0.019840) = 0
加总                        = 0.020040
```

第 1 格的权重是 0，所以那一格的 `−ln` 再大也不进入损失。损失只剩下正确那一格的 `−ln(百分比)`。百分比越接近 1，`−ln` 越接近 0。

同一格百分比，平方差 `(1 − p)²` 和 `−ln(p)` 的大小不同：

| 正确格的百分比 | `−ln(百分比)` | `(1 − 百分比)²` |
| --- | --- | --- |
| 1 | 0 | 0 |
| 0.980160 | 0.020039 | 0.000394 |
| 0.5 | 0.693147 | 0.25 |
| 0.1 | 2.302585 | 0.81 |
| 0.019840 | 3.920055 | 0.960714 |

百分比从 0.5 降到 0.1，平方差从 0.25 增到 0.81。`−ln` 从 0.693 增到 2.303。正确格分到的百分比越小，交叉熵涨得越快。

<a id="binary-meaning"></a>

## 二分类是两类交叉熵写成一个分数

「是 / 否」只有两格，两格百分比加起来是 1。记「是」的百分比为 `p`，「否」就是 `1 − p`。答案权重也只有两种：是，写成 `[1, 0]`；否，写成 `[0, 1]`。

答案是「是」：

```text
1 × (−ln p) + 0 × (−ln(1 − p)) = −ln p
```

答案是「否」：

```text
0 × (−ln p) + 1 × (−ln(1 − p)) = −ln(1 − p)
```

合在一起就是 `−[ y ln p + (1 − y) ln(1 − p) ]`。`y` 是 1 或 0，用来选出上面两行里的一行。

一个分数 `z` 可以同时给出这两格。把另一格的分数写成 0，再做两类的 Softmax，第一格就是 Sigmoid：

```text
Softmax([z, 0]) 的第 0 格 = e^z / (e^z + 1) = Sigmoid(z)
```

所以 `BCEWithLogits(3.2, 目标 1)` 等于 `CrossEntropy([3.2, 0], 类别 0)`，都是 **0.039953**。`BCEWithLogits(−0.7, 目标 0)` 等于 `CrossEntropy([−0.7, 0], 类别 1)`，都是 **0.403186**。

小明那组两类分数是 `[3.2, −0.7]`，第二格是 −0.7，不是 0。交叉熵用的是 Softmax 之后的 0.980160，损失是 0.020040。二分类那个 0.039953 来自单独一个分数 3.2，第二格被当成 0。两个数对应的百分比不一样。
