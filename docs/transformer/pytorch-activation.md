# 激活函数在网络里的哪一步生效

线性层先交出一排数。激活函数紧挨在它后面，对每一个数单独做一次换算。形状不变。下一层线性层看到的输入，是换算之后的这排数。

`F.relu` 和 `torch.relu` 是同一个换算。`nn.ReLU()` 是一个没有权重的层，前向里调用的也是这个换算。`Sequential` 里要放层，所以写成 `nn.ReLU()`。自己写的 `forward` 里可以直接写 `torch.relu(x)` 或 `F.relu(x)`。

对照脚本是 [activations.py](../../examples/pytorch/lesson2/activations.py)。

<a id="place"></a>

## 写在哪一行，就在哪一步生效

`SimpleNN` 里生效的位置是这一行：

```python
x = torch.relu(self.fc1(x))  # fc1 的输出先换算，再交给 fc2
x = self.fc2(x)
```

`fc1` 对第二行输入 `[0, −6]` 交出 `[-5, 0]`。ReLU 把它换成 `[0, 0]`。`fc2` 的权重是 `[0.4, 0.1]`，于是

```text
经过 ReLU：0.4×0 + 0.1×0 = 0
不用 ReLU：0.4×(−5) + 0.1×0 = −2
```

下一层的加权和使用的是 0，用不到 −5。激活函数的作用就落在这一步：它改写交给下一层的那排数。

<a id="three"></a>

## 三种换算

同一组线性层输出 `[-5, 0, 2]`：

| 输入 | ReLU | Sigmoid | Tanh |
| --- | --- | --- | --- |
| −5 | 0 | 0.006693 | −0.999909 |
| 0 | 0 | 0.5 | 0 |
| 2 | 2 | 0.880797 | 0.964028 |

ReLU 的规则是 `max(0, z)`。负数换成 0，正数原样送出。−5 这一格交给下一层的是 0。2 这一格交给下一层的仍是 2。

Sigmoid 的规则是 `1 / (1 + e^(−z))`。每个数都落到 0 和 1 之间。−5 变成 0.006693，仍然大于 0，下一层还会用到这个很小的数。0 变成 0.5。2 变成 0.880797。

Tanh 的规则是 `(e^z − e^(−z)) / (e^z + e^(−z))`。每个数都落到 −1 和 1 之间。−5 变成接近 −1 的 −0.999909，下一层收到的是一个负数。0 仍是 0。2 变成 0.964028。

<a id="grad"></a>

## 梯度也从这一格走

把输入加 0.001，看输出变多少，再除以 0.001，就是这一格的变化率。

| 函数 | 输入 −5 的变化率 | 输入 2 的变化率 |
| --- | --- | --- |
| ReLU | 0 | 约 1 |
| Sigmoid | 约 0.00665 | 约 0.105 |
| Tanh | 约 0.00018 | 约 0.071 |

ReLU 在 −5 的变化率是 0：这一格再降一点，送出去的仍是 0，更前面的权重从这个样本的这一格收不到梯度。输入是 2 时，变化率约是 1，梯度按原样送回上一层。

Sigmoid 和 Tanh 在 −5 仍有一个很小的变化率，梯度还能送回去，只是很小。输入越远离 0，这两种函数的变化率越小。
