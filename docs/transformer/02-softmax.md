# Softmax

阶段 2 的细读。过关标准：能写出「先取指数，再除以总和」；能说明输入差很大时，权重几乎变成 0 或 1，再改输入，输出也几乎不动。

回到 [规划表](README.md)。上一阶段是 [矩阵与点积](01-matrix-and-dot-product.md)。

<a id="why"></a>

## 分数还不能直接当百分比

上一节里，小明对三杯饮料的匹配分可以写成 `[2, 0, 1]`：珍珠 2 分，冰美式 0 分，柠檬茶 1 分。这里故意用小数，方便手算。98、60、80 那种大分，算法完全一样。

这些分数还不能当「各放多少」：

- 它们可以是 0，也可以是负数。负数没法理解成「加入两成美式」。
- 它们加起来不一定是 1。2+0+1=3，不是「一共 100%」。

注意力需要的是一套百分比，写成 0 到 1 的权重：每一项都大于 0，三项加起来正好是 1。0.665 就是 66.5%。于是可以说：100 毫升混合奶茶里，66.5 毫升是珍珠，9.0 毫升是美式，24.5 毫升是柠檬。Softmax 就是把任意一排分数变成这样一套百分比的办法。

<a id="formula"></a>

## 先取指数，再除以总和

对每个分数先做指数 `e^分数`。`e` 大约是 2.718。指数有两个有用的性质：任何实数取指数都大于 0；分数越大，结果涨得越快。

```text
珍珠  e^2 ≈ 7.389
美式  e^0 = 1
柠檬  e^1 ≈ 2.718
总和       ≈ 11.107
```

再让每一项除以这个总和，权重就加总为 1：

```text
珍珠  7.389 / 11.107 ≈ 0.665
美式  1     / 11.107 ≈ 0.090
柠檬  2.718 / 11.107 ≈ 0.245
```

0.665 + 0.090 + 0.245 = 1。写成公式，第 i 项的权重是

```text
softmax(z)_i = exp(z_i) / (exp(z_1) + exp(z_2) + … + exp(z_n))
```

最高分仍然最高：珍珠 2 分变成 66.5%，柠檬 1 分变成 24.5%，美式 0 分只剩 9.0%。指数把差距拉开了，原来 2 比 0 只大 2，权重却变成了大约 7 比 1。

<a id="mix"></a>

## 权重用来混合，不是用来排序就结束

三杯饮料的特征仍是甜、冰、茶：

```text
珍珠  [9, 1, 4]
美式  [1, 2, 8]
柠檬  [6, 7, 3]
```

用上面的权重做加权平均：

```text
甜 = 0.665×9 + 0.090×1 + 0.245×6 ≈ 7.55
冰 = 0.665×1 + 0.090×2 + 0.245×7 ≈ 2.56
茶 = 0.665×4 + 0.090×8 + 0.245×3 ≈ 4.12
```

混合结果大约是 `[7.55, 2.56, 4.12]`。它最接近珍珠 `[9, 1, 4]`，又被柠檬稍微带向更冰。倒进同一个杯子的就是这杯：甜 7.55、冰 2.56、茶 4.12。论文里的写法是 `softmax(QKᵀ / √d_k) V`。前面的矩阵乘法负责打分，softmax 负责把分数变成加总为 1 的百分比，再用这些百分比去混合每一项的特征。

<a id="negative"></a>

## 为什么不能直接除以总分

换一排有负数的分数 `[2, −1, 0]`。三数之和是 1。若直接除以总分，得到 `[2, −1, 0]`。−1 不能当作「加入负的一份美式」，2 也不表示「两成」。

先取指数：

```text
e^2  ≈ 7.389
e^−1 ≈ 0.368
e^0  = 1
总和  ≈ 8.757
```

权重约为 `[0.844, 0.042, 0.114]`。最低的那一项仍然有一点正的份额，三项之和为 1。负数分数只是表示「比 0 更不匹配」，指数把它变成一个很小的正数。

<a id="equal"></a>

## 分数相同，权重就平分

`[1, 1, 1]` 的指数都是 `e^1`，除以总和之后各是 `1/3`。不必死记 `e^1`：只要所有分数一样，指数也一样，权重就平均分。谁也不比谁更匹配时，注意力均匀地看每一项。

<a id="saturate"></a>

## 分差很大时，权重会饱和

把两杯的分数拉开，再看权重怎么变。

| 分数 | 权重 |
| --- | --- |
| 1 与 0 | 0.731 与 0.269 |
| 5 与 0 | 0.993 与 0.007 |
| 8 与 0 与 0 | 0.999 与 0.0003 与 0.0003 |

5 已经比 0 高出 5 分时，第一项拿走 99.3%。8 分对 0 分时，几乎变成「全看第一项」。这种一端接近 1、其余接近 0 的状态，叫做饱和。

饱和之后，再改输入，输出几乎不动。把落后的那一项加 0.5 分：

| 改动 | 领先项的权重 |
| --- | --- |
| `[1, 0]` 改成 `[1, 0.5]` | 0.731 → 0.622，下降 0.109 |
| `[5, 0]` 改成 `[5, 0.5]` | 0.993 → 0.989，只下降 0.004 |

接近时，半分就能明显重分配力。已经拉开时，同样的半分几乎没有作用。训练时要靠「改分数会怎样改变权重」来学习。输出几乎不动，这个学习信号就接近 0。人们把输出对输入的敏感程度叫做梯度，所以说：softmax 进入饱和区时，梯度接近 0。

论文里的点积在维度大时很容易变成 8、10 这种大数。除以 `√d_k` 就是在进 softmax 之前把分差缩小，避免权重过早变成独热、学习信号消失。

<a id="scale"></a>

## 先缩小分数，分布会变平

同一组 `[2, 0, 1]`，先除以 2 再做 softmax，等于把分差缩小：

```text
[2, 0, 1]     →  0.665, 0.090, 0.245
[1, 0, 0.5]   →  0.506, 0.186, 0.307
[4, 0, 2]     →  0.867, 0.016, 0.117
```

除完之后，珍珠从 66.5% 降到 50.6%，美式从 9.0% 升到 18.6%，三杯更平均。反过来先乘 2，珍珠升到 86.7%，弱项更弱。`√d_k` 那个除法，作用就是把点积推进这张表的中间一行，而不是最尖的那一行。

<a id="check"></a>

## 过关自测

先盖住答案。指数可以只保留三位小数：`e^1 ≈ 2.718`，`e^2 ≈ 7.389`，`e^0 = 1`。

1. 对分数 `[1, 1]` 做 softmax。
2. 对分数 `[0, 1]` 做 softmax，并说明哪一项更大。
3. 分数是 `[0, 10]` 时，权重会更接近平均，还是更接近「全给第二项」？用饱和来说明，不必把 `e^10` 算到底。

答案：

1. 两项指数相同，权重各是 0.5。
2. `e^0 = 1`，`e^1 ≈ 2.718`，总和约 3.718。权重约为 `[0.269, 0.731]`。第二项更大，因为 1 比 0 更匹配。
3. 更接近「全给第二项」。10 和 0 的差距远大于前面的 5 和 0，而 5 和 0 已经是 0.993 对 0.007。落后项再改一点，领先项的权重也几乎不动。
