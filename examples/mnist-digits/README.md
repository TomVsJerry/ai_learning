# 读手写数字

这是一个可以运行的人工神经网络：看一张手写数字图，输出 0 到 9 的百分比。银行支票和邮政编码上的数字识别，用的是同一条流水线；这里把网络收成两层，方便对上前面的笔记。

在本目录运行：

```text
pip install -r requirements.txt
python train.py --epochs 2
```

第一次运行会把 MNIST 下载到 `data/`。这个目录不提交进 git。

## 框架

```text
一张 28×28 的图
    ↓  ToTensor，亮度从 0～255 收到 0～1
784 个数
    ↓  线性层 W1、b1，再 ReLU
128 个检测
    ↓  线性层 W2、b2
10 个分数（像 0 …… 像 9）
    ↓  交叉熵损失内部做 Softmax
正确那一类的百分比越接近 1，损失越小
    ↓  Adam 改 W1、b1、W2、b2
```

输入和输出：

| | 形状 | 含义 |
| --- | --- | --- |
| 一张图 | 1×28×28 | 1 个颜色通道，28 行 28 列亮度 |
| 拉直后 | 784 | 交给线性层的一行特征 |
| 一批 | 64×1×28×28 | 一次同时算 64 张，权重仍是同一套 |
| 分数 | 64×10 | 每张图 10 个数字各一个分数 |
| 标签 | 64 个整数 | 每个数是 0～9，表示正确百分比在第几格 |

模型写在 `model.py`。`DigitClassifier` 里只有两层 `Linear`。`forward` 返回分数，不在这里做 Softmax。`CrossEntropyLoss` 内部会做，并且用更稳的算法，避免先求指数时溢出。10 个分数里最大的那一格，和百分比最大的那一格是同一个数字，所以读结果时直接取分数最大的下标。

## 训练在做什么

每一批：

1. 用当前的 `W`、`b` 把 64 张图算成 64×10 的分数。
2. 算出这一批的平均损失。
3. `loss.backward()` 算出每个参数该往哪边改。
4. `optimizer.step()` 改 `W1`、`b1`、`W2`、`b2`。

训练集大约 6 万张，测试集约 1 万张。测试图不参与改参数，用来看没见过的字读得怎样。

128 个检测没有预先起名。训练只看到「这张图的标签是 3」，然后改权重。训完以后，有的检测会比较像某一小段笔画，那是人看权重时的解释。

## 和奶茶例子的对应

| 奶茶网络 | 这个项目 |
| --- | --- |
| 甜、冰、茶，3 个数 | 784 个亮度 |
| 清爽、甜腻，2 个中间格 | 128 个检测 |
| 喜欢、不喜欢，2 个分数 | 0～9，10 个分数 |
| 手写的 `W` | `nn.Linear` 里随机起步、再由训练改掉的 `W` 和 `b` |
| `−ln(正确百分比)` | `nn.CrossEntropyLoss` |
